# SC CRM Comercial

CRM web responsive para gestionar la prospección comercial de **SC Soluciones Conectadas** y **Click**.

## MVP actual

- Dashboard comercial.
- Alta y edición de prospectos.
- Búsqueda y filtros.
- Pipeline visual por etapas.
- Seguimientos vencidos, de hoy y próximos.
- Historial de interacciones.
- Acceso directo a WhatsApp.
- Reportes por rubro y responsable.
- Tema claro/oscuro.
- Persistencia local con localStorage.
- Exportación JSON.
- Diseño responsive para escritorio y celular.

## Privacidad

Esta versión es solo frontend y no contiene contactos reales en el repositorio. Para producción se conectará a Supabase/PostgreSQL con autenticación y Row Level Security.
