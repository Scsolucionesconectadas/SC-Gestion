# Fuente visual oficial — SC Soluciones Conectadas

Este CRM toma como fuente de identidad los archivos de marca provistos por SC.

## Paleta oficial
- Celeste SC: `#31A5D6`
- Azul SC: `#0360BD`
- Gris oscuro SC: `#2C3A46`

## Criterio de uso en CRM
- Gris oscuro como base institucional y navegación.
- Azul como acción primaria y estados activos.
- Celeste como acento, conectores, foco y microanimaciones.
- Fondos claros y blancos para lectura de tablas y formularios.
- El isotipo SC se usa como identificador compacto del producto.
- Las variantes blancas quedan reservadas para fondos azul/celeste/gris oscuro.

## Activos
- `assets/img/sc-isotipo-color.webp`: versión web optimizada del isotipo oficial entregado por SC.

Los originales de marca se conservan fuera del frontend optimizado. No reemplazar el símbolo por recreaciones tipográficas o aproximaciones.
