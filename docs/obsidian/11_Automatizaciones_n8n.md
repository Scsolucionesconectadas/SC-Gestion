# Automatizaciones n8n

No hay workflows n8n conectados en esta versión.

## Diseño previsto

- Triggers desde cambios relevantes o webhooks autenticados.
- Validación de `organization_id` en cada ejecución.
- Reintentos con límite, alertas y bitácora.
- Aprobación humana para mensajes, presupuestos y acciones financieras.
- Secretos únicamente en credenciales de n8n, nunca en el frontend.
